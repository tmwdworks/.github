# TMWD Works Brand Assets

Public brand assets for TMWD Works.

## Files

- `tmwdworks-logo.png` — finalized raster reference on white
- `tmwdworks-logo-transparent.png` — cleaned transparent-background logo
- `tmwdworks-logo.svg` — flat-color vector trace for scalable use
- `tmwdworks-logo-monochrome.png` — monochrome transparent PNG
- `tmwdworks-logo-monochrome.svg` — monochrome vector version
- `tmwdworks-icon.png` — square compact TMWD icon for profile images
- `tmwdworks-icon.svg` — scalable square compact icon
- `brand-colors.json` — fixed brand color values

## Brand colors

| Role | HEX |
| --- | --- |
| Wordmark black | `#131312` |
| Lime arc | `#8ECB3C` |
| Vermilion digital accent | `#F94122` |
| White background | `#FFFFFF` |

## Notes

The SVG assets are clean flat-color vector traces derived from the finalized raster artwork.
They do not contain a colored background rectangle.

The transparent PNG and icon assets use the same fixed palette as the SVG files.

These assets are brand materials and are not released under an open-source license.
