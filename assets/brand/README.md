# TMWD Works Brand Assets

Finalized public brand assets for TMWD Works.

## Files

- `tmwdworks-logo.png` — finalized raster reference on white
- `tmwdworks-logo-transparent.png` — transparent-background logo
- `tmwdworks-logo.svg` — vector-traced logo for scalable use
- `tmwdworks-logo-monochrome.png` — monochrome transparent PNG
- `tmwdworks-logo-monochrome.svg` — monochrome vector version
- `tmwdworks-icon.png` — square/compact icon for profile images
- `tmwdworks-icon.svg` — scalable compact icon
- `brand-colors.json` — fixed brand color values

## Brand colors

| Role | HEX |
| --- | --- |
| Wordmark black | `#131312` |
| Lime arc | `#8ECB3C` |
| Vermilion digital accent | `#F94122` |
| White background | `#FFFFFF` |

The lime and vermilion values are fixed from the finalized visual direction.

## Notes

The SVG files are vector traces of the finalized raster artwork. They scale without raster pixelation, but if the logo is later professionally redrawn, that redrawn SVG should replace the traced master.

These assets are brand materials and are not released under an open-source license.
